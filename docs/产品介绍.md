# 山海行 · 文旅多 Agent 行程规划系统 — 产品介绍

> 版本 v3.1 · 2026-09-05

---

## 一、这是什么

**山海行**是一款基于 **8 个 AI Agent 协作**的文旅行程规划系统。用户只需要用**一句话、一个表单、一次对话，甚至一段语音**说出旅行需求，系统就能自动完成：

> 需求解析 → 真实数据调研 → 个性化行程编排 → 预算计算 → 风险审核 → 生成完整报告

全程使用**真实数据**（高德地图景点/路线/天气 + 阿里云百炼大模型），不是假数据拼凑。

---

## 二、它解决什么问题

传统旅行规划靠**人工查资料 + Excel 排行程**，一个行程从需求到方案要几小时到一整天。而且有 7 个硬伤：

| # | 痛点 | 山海行的解法 |
|---|---|---|
| 1 | 查到的信息会过时 | 接入**高德地图实时数据**（景点/营业时间/评分/天气/路线）|
| 2 | 可能推荐差评景点、超预算、夜行路段 | **HITL 人工审核**：超预算 45%、高危夜行、严重舆情自动挂起给主管审批 |
| 3 | 查到一半崩溃全丢 | **断点续传**：原子写入 + 快照，崩溃 5 秒内恢复，不重复执行 |
| 4 | 用户偏好被遗忘（"我海鲜过敏"下次忘了）| **图记忆**：跨行程沉淀知识图谱，下次自动避开过敏原 |
| 5 | 运行中景点停运，系统不知道 | **运行态强干预**：主管带验签实时修改运行中行程 |
| 6 | 不管老人儿童，行程千篇一律 | **人群个性化适配**：老人/儿童门票按年龄分档、景点过滤、兴趣推荐 |
| 7 | 景区政策靠写死代码或 LLM 编造 | **RAG 检索增强**：先查知识库，再基于真实资料生成，有据可查 |

## 三、核心功能

### 3.1 多种创建方式

| 方式 | 说明 | 适合谁 |
|---|---|---|
| **新建行程**（表单）| 填写出发地/目的地/天数/预算/同行人明细 | 需求明确、要精细控制 |
| **语音创建** | 用嘴说需求，浏览器语音转文字生成 | 不想打字 |
| **对话式创建** | AI 主动引导，像 DeepSeek 一样聊天收集需求 | 需求模糊、想边聊边定 |

### 3.2 完整行程规划

- **每日三餐**：早餐（不吃火锅/烤鸭，吃地方特色早餐）、午餐、晚餐，三餐跨天不重复
- **真实景点**：高德真实 POI，含图片（可放大）、营业时间、评分、地址
- **门票分档**：成人/儿童/老人按年龄分档，景点标注优待政策
- **往返交通**：去程/返程方式 + 票价（高铁/飞机按年龄购票）+ 耗时 + 途中建议
- **预算明细**：交通/住宿/门票/餐饮/其他 分项汇总，超预算自动提示

### 3.3 人群个性化适配

| 人群 | 适配逻辑 |
|---|---|
| **老人** | 门票 60-64 半价、65+ 免首道；剔除滑雪/登山/雪山等高强度项目 |
| **儿童** | 门票 6 岁以下或 1.2 米以下免票、6-18 半价；高铁 6 岁以下免票不占座；剔除酒吧/夜店 |
| **学生** | 高铁学生票仅限家校往返（旅游不推荐）；飞机无学生优惠 |

### 3.4 RAG 检索增强

- **文旅知识库**：6 类语料（景点攻略/地方美食/景区政策/四季玩法/交通贴士/住宿贴士）
- **AI 目的地解读**：报告里 AI 基于知识库生成目的地亮点、美食推荐、老人儿童注意事项

### 3.5 安全与权限

- 三种角色：游客 / 旅行顾问 / 主管（RBAC 权限分离）
- Prompt 注入检测 + 网页内容安全过滤 + 审计日志
- 密钥安全注入（不入代码库）

## 四、技术架构（6 层）

```
前端层    React 18 + TypeScript + AntD
         （8 个页面，11 国语言，WebSocket 实时推送）
            │
API 网关  FastAPI + JWT/RBAC + 统一错误码 + HMAC 验签
            │
业务服务  高德服务 / 原子写 / 分布式锁 / 队列 / 恢复 / 安全过滤
            │
Agent 编排 LangGraph StateGraph + 8 节点 DAG + 条件边
            │
数据层    PostgreSQL(pgvector) + Redis + 文件（11 张表 + 知识库向量）
            │
外部数据源 高德地图 + 阿里云百炼(LLM + Embedding)
```

---

## 五、8 个 AI Agent 协作流程

```
① Intake 偏好解析   → 解析需求为结构化偏好
② Planner 任务拆解  → 拆解调研任务（景点/酒店/餐厅/早餐/交通）
③ Web Research 调研 → 调高德搜真实 POI + 检索知识库
④ Sentiment 舆情    → 识别风险标签
⑤ Itinerary 编排    → 按天排行程 + 人群过滤 + 门票分档
⑥ Budget 预算       → 分项汇总 + 判断超预算
⑦ Human Review 审核 → 风险场景挂起人工审批
⑧ Report 报告       → 生成完整报告 + AI 目的地解读
```

条件边：超预算 45% / 高危夜行 / 严重舆情 → 挂起人工审核，通过后续跑，否则直接出报告。

## 九、亮点总结

1. **全链路真实数据**：高德 + 百炼，无假数据假智能
2. **断点续传**：崩溃 5 秒恢复，不丢进度不重复执行
3. **人群适配**：老人/儿童/学生按规则分档，行程千人千面
4. **RAG 检索增强**：知识库 + 语义向量 + AI 解读，有据可查
5. **HITL 人工审核**：风险自动挂起，主管门控
6. **图记忆 + 强干预**：跨行程记住偏好，运行态实时纠偏
7. **多种创建方式**：表单 / 语音 / 对话式，降低使用门槛
