# 更多地方美食详解

## 川菜系
川菜以"一菜一格、百菜百味"著称，代表有麻婆豆腐、回锅肉、宫保鸡丁、水煮鱼、夫妻肺片。川菜麻辣鲜香，但并非全辣，也有咸鲜味、甜味菜。老人儿童可选不辣或少辣菜品。成都、重庆是川菜两大重镇，火锅、串串、冒菜是市井代表。

## 粤菜系
粤菜讲究清、鲜、嫩、滑，代表有白切鸡、烧鹅、叉烧、虾饺、肠粉。粤菜口味清淡，非常适合老人儿童。广州早茶文化是粤菜代表，虾饺、烧卖、凤爪、糯米鸡是经典茶点。广东煲汤文化深厚，老火靓汤养生。

## 江浙菜系
江浙菜甜咸适中、清淡鲜美，代表有西湖醋鱼、东坡肉、龙井虾仁、叫花鸡、清蒸鲥鱼。江浙菜讲究火候和刀工，口味温和，老人儿童接受度高。杭州、苏州、扬州是江浙菜代表城市，扬州炒饭、蟹粉狮子头是名菜。

## 鲁菜系
鲁菜是八大菜系之首，讲究咸鲜、脆嫩，代表有葱烧海参、糖醋鲤鱼、九转大肠、德州扒鸡。鲁菜历史悠久，孔府菜是鲁菜的高端代表。山东是鲁菜发源地，青岛、济南、烟台海鲜丰富。

## 湘菜系
湘菜香辣浓郁，代表有剁椒鱼头、辣椒炒肉、湘西腊肉、口味虾。湘菜比川菜更辣，老人儿童需特别注意。长沙是湘菜代表城市，臭豆腐、糖油粑粑、口味虾是街头小吃。湘西地区腊肉、酸菜是特色。

## 地方小吃地图
- 北京：豆汁、焦圈、炒肝、卤煮、驴打滚
- 天津：狗不理包子、煎饼果子、锅巴菜
- 西安：羊肉泡馍、肉夹馍、凉皮、biangbiang面
- 兰州：牛肉拉面
- 新疆：烤羊肉串、大盘鸡、手抓饭、馕
- 云南：过桥米线、汽锅鸡、鲜花饼、饵丝
- 广西：桂林米粉、螺蛳粉、老友粉
- 福建：佛跳墙、沙县小吃、海蛎煎
- 台湾：蚵仔煎、牛肉面、珍珠奶茶、凤梨酥
